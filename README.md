# About the Agentic System

**A Group Project Planning Agent (DRAFT)**

> **Problem to be solved**: A student group has been handed a project with a rubric and a due date. The rubric lists a few large, vague deliverables ("market analysis," "financial model"), so nobody knows what to do first. Work stays vague until days before the deadline, and when someone gets stuck or behind, the plan has no way to adapt. The team needs a plan that is small enough to act on and a way to repair it when it slips.

*Chosen problem: Option 2, Turn overwhelming study tasks into next steps (narrowed to group projects).*

### System Goal

**For** members of a student group project team, **make** the project manageable, **measured by** the share of rubric points covered by concrete steps (2 hours or less, a named owner, and a due date) **moving from** about 0% (the rubric is the only plan) **to** 100%, and by whether every member can name their next step, **without** reassigning anyone's work or contacting teammates without their approval.

> Baseline is an estimate to confirm before the showcase.

### Who Is Better Off When This Works?

Every team member: each person can name a concrete next step, and the team can see at a glance which parts of the rubric are covered, on track, or at risk.
